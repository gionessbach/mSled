# mSled

Schlittenbahnen malen und losflitzen: Bahn, Turbo und Deko zeichnen, dann rutscht der Fahrer mit echter Physik hinab, springt, dreht Saltos oder fällt runter. iPad-Web-App für Kinder im Stil von mZip.

**Spielen:** https://gionessbach.github.io/mSled/

Auf dem iPad in Safari öffnen und über *Teilen → Zum Home-Bildschirm* hinzufügen.

Bei Änderungen an der App in `sw.js` die Versionsnummer (`msled-v1`) erhöhen, damit installierte Geräte die neue Version laden.
